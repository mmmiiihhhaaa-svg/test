# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## На разработку расширения для Google Chrome «Экранная лупа» (Screen Magnifier)

---

## 1. Общие сведения

- **Платформа:** Google Chrome (и браузеры на базе Chromium: Edge, Brave, Opera)
- **Версия манифеста:** Manifest V3 (обязательно)
- **Главная цель:** Создание легкого, быстрого и отзывчивого инструмента для увеличения области экрана под курсором мыши без просадок FPS и блокировки взаимодействия со страницей

---

## 2. Функциональные требования (Основной функционал)

### 2.1. Формы и внешний вид лупы

- Поддержка двух форм: **Круг** и **Квадрат**
- Наличие опциональной границы (обводки) лупы
- Эффект «линзы»: увеличение области страницы под курсором
- **Улучшение:** Визуальная индикация текущего уровня зума внутри лупы (цифры, например "2.0x")

### 2.2. Управление зумом (Масштабированием)

- Регулировка уровня зума колесиком мыши при зажатой клавише-модификаторе (по умолчанию `Shift`)
- Значение зума ограничено настройками (мин/макс) и изменяется с заданным шагом
- При достижении мин/макс значений дальнейшая прокрутка колесика игнорируется
- **Улучшение:** Визуальная обратная связь при достижении лимита (кратковременная пульсация границы)

### 2.3. Управление яркостью

- Регулировка яркости увеличенной области колесиком мыши при зажатых клавишах `Alt + Shift`
- Значение яркости ограничено настройками (мин/макс) и изменяется с заданным шагом
- **Улучшение:** Визуальный индикатор яркости (прогресс-бар внутри лупы)

### 2.4. Качество изображения

- Настройка сглаживания (Anti-aliasing / Image Smoothing)
- Возможность переключения между четким (пиксельным) и сглаженным увеличением

---

## 3. Поведение и взаимодействие (UX)

### 3.1. Активация и деактивация

- **Горячая клавиша:** Нажатие назначенной комбинации (по умолчанию `Ctrl + Shift + M`) показывает лупу. Повторное нажатие — скрывает
- **Клик по иконке:** Клик по иконке расширения в панели Chrome показывает/скрывает лупу
- **Скрытие кликом:** Клик в любом месте веб-страницы скрывает лупу
- **Важно:** Лупа НЕ перехватывает клики (`pointer-events: none`), клик по странице триггерит скрытие лупы
- **Улучшение:** Скрытие при уходе курсора за пределы окна браузера (`mouseleave` на `window`)
- **Реализация:** Скрытие по событию `mousedown` на `document`

### 3.2. Отслеживание курсора

- Лупа плавно следует за курсором мыши
- Для обеспечения плавности использовать `requestAnimationFrame`
- **Улучшение:** Дебаунсинг захвата экрана через `requestIdleCallback` или throttle (60fps → ~30fps для захвата)

### 3.3. Состояния лупы

| Состояние | Описание |
|-----------|----------|
| Неактивна | Лупа скрыта, расширение ожидает активации |
| Активна | Лупа видна и следует за курсором |
| Зум | Колесико мыши изменяет масштаб (при зажатом модификаторе) |
| Яркость | Колесико мыши изменяет яркость (при зажатом Alt+Shift) |

## 4. Страница настроек (Options Page)

Настройки сохраняются в `chrome.storage.sync` (с фоллбэком на `local`). Применение — мгновенное.

| Параметр | Тип | По умолчанию | Ограничения |

| Форма лупы | Переключатель (Radio) | Круг | Круг / Квадрат |
| Размер лупы | Числовое поле (px) | 256 | от 50 до 800 px |
| Граница лупы | Чекбокс | Вкл | Вкл/Выкл |
| Цвет границы | Color picker | #00AAFF | Любой HEX |
| Толщина границы | Числовое поле (px) | 2 | от 1 до 10 px |

| Параметр | По умолчанию | Ограничения |
|----------|--------------|-------------|
| Минимальный зум | 1.5x | от 1.1x |
| Максимальный зум | 5.0x | до 10.0x |
| Шаг зума | 0.25x | от 0.1x до 1.0x |

### 4.3. Параметры Яркости

| Параметр | По умолчанию | Ограничения |
|----------|--------------|-------------|
| Минимальная яркость | 0.5 | от 0.1 |
| Максимальная яркость | 2.0 | до 3.0 |
| Шаг яркости | 0.1 | от 0.05 до 0.5 |

### 4.4. Горячие клавиши

| Параметр | По умолчанию | Примечание |
|----------|--------------|------------|
| Включение/Выключение лупы | `Ctrl + Shift + M` | Реализуется через `chrome.commands` в manifest.json |
| Модификатор для Зума | `Shift` | Проверяется через JS в content script |
| Модификатор для Яркости | `Alt + Shift` | Проверяется через JS в content script |

**Улучшение:** Модификаторы зума и яркости настраиваются на странице настроек (выбор из: Shift, Ctrl, Alt, None)

### 4.5. Качество изображения

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|

## 5. Технические требования (Архитектура и Производительность)

### 5.1. Архитектура расширения

```
│                                              │
│  ┌──────────────┐  ┌──────────────────────┐  │
│  │ service_     │  │   content_script     │  │
│  │ worker       │  │   (injected on tab)  │  │

│  │              │  │  ┌────────────────┐   │  │
│  │ - Hotkey     │  │  │ Magnifier      │   │  │
│  │ - Toggle     │  │  │ Overlay (DOM)  │   │  │
│  │     state    │  │  │   └─ Canvas    │   │  │
│  └──────┬───────┘  │  └────────────────┘   │  │
│         │          │                       │  │
│         │ Chrome   │  ┌────────────────┐   │  │
│         │ Messages │  │ Options Page   │   │
│         │          │  │ (html + js)    │   │  │
│         └──────────┘  └────────────────┘   │  │
└─────────────────────────────────────────────┘
```

### 5.2. Рендеринг лупы — РЕАЛИЗАЦИЯ

**Выбранный подход: Canvas + `chrome.tabs.captureVisibleTab`**

1. Content script создаёт overlay-элемент (div с canvas)
2. При движении мыши — асинхронный захват видимой области вкладки через `chrome.tabs.captureVisibleTab`
3. Захваченное изображение рисуется на canvas внутри лупы, масштабированное согласно текущему зуму
4. Яркость применяется через CSS `filter: brightness()` на canvas
5. Дебаунсинг/Throttle захвата экрана до ~30fps для баланса производительность-качество

**Почему не другие подходы:**
- ❌ `backdrop-filter: scale()` — не существует в CSS
- ❌ Клонирование DOM-элементов — не работает для `<canvas>`, `<video>`, `<iframe>`, слишком тяжело
- ❌ Постоянный `captureVisibleTab` без оптимизации — высокие CPU/GPU затраты

### 5.3. Оптимизация производительности

| Метрика | Цель |
|---------|------|
| FPS лупы | ≥ 24 fps (захват экрана), 60 fps (отрисовка DOM) |
| CPU нагрузка | ≤ 5% на среднем десктопе |
| Размер расширения | ≤ 2 MB |

**Техники оптимизации:**
- Throttle захвата экрана до ~30fps (через `performance.now()` + интервал)
- Не захватывать экран, если лупа не видна или мышь не двигается
- Использовать `requestAnimationFrame` только для перемещения DOM-элемента лупы
- Захват экрана через `requestIdleCallback` или setTimeout с debounce
- CSS: `will-change: transform`, `transform: translate3d(...)` для GPU-ускорения
- `pointer-events: none` на контейнере лупы

### 5.4. Обработка событий

- При зажатых модификаторах (`Shift` или `Alt+Shift`) и прокрутке колесика — `event.preventDefault()`, чтобы страница не скроллилась
- `mouseleave` на `window` — скрыть лупу
- `mousedown` на `document` — скрыть лупу (если лупа активна)

### 5.5. Manifest V3

- `service_worker` — только для управления состоянием (вкл/выкл лупы)
- `content_scripts` — внедряются динамически через `chrome.scripting.executeScript` при активации
- `chrome.commands` — регистрация горячей клавиши
- `chrome.action.onClicked` — клик по иконке расширения

### 5.6. Обработка ошибо��

| Сценарий | Поведение |
|----------|-----------|
| `captureVisibleTab` не доступен (chrome://, edge:// страницы) | Показать предупреждение в лупе: "Захват экрана недоступен на этой странице" |
| Сайт с canvas/WebGL (YouTube, Google Maps) | Лупа покажет захваченный кадр, но canvas не будет обновляться в реальном времени (ограничение браузера) |
| `<iframe>` с другим origin | Лупа не сможет захватить содержимое iframe (ограничение безопасности) |
| Недостаточно памяти для захвата | Показать сообщение об ошибке, деактивировать лупу |

## 6. Требования к UI/UX иконки

- **Иконка:** SVG/PNG, визуальный отклик состояния
  - 🔵 Неактивно: синяя лупа
  - 🟢 Активно: зелёная лупа
- **Popup:** Не требуется. Клик по иконке → toggle лупы через `chrome.action.onClicked`
- **Улучшение:** Бейдж с текущим уровнем зума (например "2x") на иконке при активной лупе

## 9. Важные примечания для разработчика

1. **Ограничения браузеров:**
   - Нет прямого API для "честного" копирования пикселей в реальном времени
   - Лупа может некорректно работать внутри `<iframe>` или на сайтах с `<canvas>`/`WebGL` (YouTube, Google Maps, онлайн-игры)
   - **Решение:** Graceful degradation — показать предупреждение пользователю

2. **Горячие клавиши для колесика:** Chrome не позволяет назначать горячие клавиши на колесико мыши через `chrome.commands`. Логика строится на проверке `event.shiftKey` / `event.altKey` в content script.

3. **Клик для скрытия:** `pointer-events: none` позволяет кликам проходить сквозь лупу. Клик по странице закрывает лупу (событие `mousedown` на `document`).

4. **Безопасность:** Content script не имеет доступа к `window` страницы, только к DOM. Для коммуникации с service worker используется `chrome.runtime.sendMessage`.

5. **Кросс-браузерность:** Тестирование на Chrome, Edge, Brave, Opera.
